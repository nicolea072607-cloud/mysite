Strike a Chord starter website files

Included:
- index.html
- lessons.html
- contact.html
- style.css
- images/ folder (put your assignment image files here)

Important:
1. Copy the image files from strike3.zip into the images folder.
2. Check that the three lesson image filenames match exactly:
   piano-lesson.jpg, child-guitar.jpg, woman-violin.jpg
3. The navigation also links to instructors.html and rentals.html, but those pages are not included in this starter set yet.
4. Upload the HTML files, style.css, and images folder to your course web server to publish the site.
5. This starter set does not yet include the Wild Rescues website.
